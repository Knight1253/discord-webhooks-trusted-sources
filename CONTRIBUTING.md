# Contributing

Thanks for helping improve this independent Discord webhook reference.

- Cite current official Discord docs for API behavior and mark community sources as secondary.
- Do not submit real webhook URLs, tokens, bot credentials, or private server data.
- Keep runnable examples scoped and safe by default; avoid unsolicited or bulk messaging patterns.
- State supported Python/runtime versions and test instructions for code changes.
- Explain any API limitations and link to the relevant official reference.

Report leaked credentials privately and rotate them immediately; never include them in an issue.
